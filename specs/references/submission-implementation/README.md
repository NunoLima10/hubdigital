# Implementation browser checks

Screenshots from the local development app, using isolated fictional test accounts. Those accounts and their projects were removed after verification. These capture the implemented UI using HubDigital tokens, rather than Product Hunt styling.

- [Geography form, mobile](./geography-form-mobile.png): public pin and optional location fields.
- [Project editing, mobile](./project-edit-mobile.png): optional profile information and submission layout.
- [Diaspora map, mobile](./diaspora-map-mobile.png): Portugal filter, matching secondary bases and country aggregation.
- [Community feed, mobile](./community-feed-mobile.png): independent announcements above the permanent directory.
- [Reviewed edit, desktop](./reviewed-edit-desktop.png): staff comparison of current and proposed pages.
- [Creator invitation, mobile](./creator-invitation-mobile.png): consent in a dashboard with no owned projects.

Desktop and 390 px browser flows were exercised with no horizontal overflow. Map/list updates, invitation acceptance, publication, owner edits, admin decisions and resulting public pages were verified through the running app.
